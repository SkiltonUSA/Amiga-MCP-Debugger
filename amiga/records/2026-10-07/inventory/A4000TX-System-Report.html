Scope and evidence

Inventory of the real A4000TX at 10.0.0.40, collected over its AmigaBridge connection on 7 October 2026 (Mac clock). This is a live hardware/OS inventory, supported by prior installation records and clearly identified manufacturer specifications.

No persistent Amiga configuration, firmware or installed application was changed. Read-only queries and two small native inventory programs were staged in RAM:; their outputs were copied to this Mac. The disk inquiries were limited to mounted devices and used INQUIRY and READ CAPACITY. No media scan, format, repair, benchmark, reboot or audio playback was performed.

“Live” means reported by this running machine. “Owner” means supplied in the conversation. “Specification” describes a product family, not a physical inspection. “Prior verification” records earlier tests, not a new test today. Unidentified revisions, serials and chip markings remain unknown. This report is an inventory, not a full disk backup.

Collected: 2026-10-07T20:47:14+00:00. Free-memory, task, socket and disk-usage figures are snapshots taken at different points during collection, while ScummVM was running. 1 MiB = 1,048,576 bytes; 1 GiB = 1,073,741,824 bytes; decimal GB = 1,000,000,000 bytes.

Fast RAM total: 654,311,424 bytes = 624 MiB. Chip RAM reported total: 2,093,056 bytes. At the initial snapshot, Fast RAM free was 596,232,368 bytes (568.61 MiB) and Chip RAM free was 1,889,728 bytes (1.80 MiB). These live totals supersede the earlier owner estimate of 284 MB Fast RAM.

Exec memory headers begin 32 bytes into each listed region. The address ranges above describe the map; allocation metadata accounts for the small difference in usable memory. Priority 40/30/20/−10 establishes the OS allocation preference, not measured memory speed.

The ZZ9000’s 128 MiB graphics/register aperture is an address window, not another 128 MiB to add to system RAM. Its onboard DDR3, ARM workspace, graphics buffers and exposed 256 MiB Amiga Fast RAM are overlapping uses of the same card memory. Do not add the full card DDR3 specification to the 624 MiB OS total.
