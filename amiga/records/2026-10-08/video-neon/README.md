# Physical NEON decoder measurement — 2026-10-08

A4000TX / ZZ9000 XX19c / XACP 1.7. All 225 frames in nine runs matched the
native references. Three alternating 320x240 runs per build: scalar 78.257 ms,
NEON-enabled 62.225 ms per decoded frame; complete playback 2.125/2.194 fps.
Both decoder builds use -O3 with instruction cache on and data cache/MMU off.
The NEON build also uses VFP via softfp. This does not isolate SIMD alone.
No FFmpeg code was used in these measurements.

`summary.json` records the medians and all-run counts; per-run JSON/log files
retain raw ticks, estimated timer frequency, stage times, output hashes, MCP
calls, state restoration and exit results. `scalar-build.json` and
`neon-build.json` identify the executables; build-time execution flags remain
false because build success itself cannot establish hardware execution.
`inputs.json` records source, clip and uploaded manual hashes. `.hashes` files
are the native frame references; clip bytes are generated by the video tests.

`shutdown.json` and `controls.log` record the additional bounded paused-debugger
quit check. `postflight.txt` confirms zero clients, no owner/video window and
the unchanged installed player MD5. Temporary Mac HTTP staging has stopped.
`tests.log` and the component/loader logs cover local validation.

See [the investigation](../../../../docs/amiga-video-arm-execution.md) for
methodology, limitations, build/staging instructions and the FFmpeg/gen2brain
source review. These measurements fail the user's 25 fps playback requirement.
